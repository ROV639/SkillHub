# Workflow：外部仓库体检

用于判断一个 GitHub 仓库是否值得学习、改写或进入 SkillHub。

## 检查项

1. README 是否清楚。
2. License 是否明确。
3. 最近提交、release、issue、PR 是否活跃。
4. 是否有安装步骤、示例输入输出、测试。
5. 是否含硬编码路径、key、cookie、session、登录态。
6. 是否会写外部平台、发布、删除、互动。
7. Rubin 能迁移的是方法、结构、模板，还是完整工具。

## 输出

```text
结论：
成熟度：
Rubin 可迁移价值：
风险：
建议动作：SHIP / FIX-FIRST / HOLD / BLOCK
可直接学习：
需要改写：
只读参考：
禁止生产化：
下一步：
```
