## 统一验收

每个 Skill 只看 5 件事：

1. 是否能服务 Rubin Studio 的真实产出。
2. 是否能减少人工试错。
3. 输出是否能进入发布、交付或复用流程。
4. 风险是否被正确挡住。
5. 是否值得从 LAB 晋升到 READY。

## 测试输入原则

- 使用 Rubin 真实任务，不用玩具样例。
- P0 先测功能价值，P1 先测流程价值。
- 只做本地草稿、方案、文件生成和 QC。
- 不做真实发布、账号登录、cookie/session、自动互动。
